# Calendario Northwood

Planeación anual de eventos de Iglesia Northwood.

- **Ver:** abre el link de GitHub Pages. No necesita contraseña.
- **Editar:** botón **Editar** → contraseña. Los cambios se guardan solos en `eventos.json` (cada guardado queda en el historial del repo).
- **Primera vez:** al tocar Editar sin configuración, la página pide un *fine-grained token* de GitHub (solo este repo, permiso *Contents: Read and write*) y una contraseña. El token se guarda cifrado en `editor.json`.

Colores: domingo (servicio), miércoles (servicio), domingo con evento, evento otro día, fin de semana festivo de EE. UU., fecha recomendada.

Para cambiar la contraseña: borra `editor.json` del repo y vuelve a tocar Editar.
