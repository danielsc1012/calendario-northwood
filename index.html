      Configurar edición (una sola vez)

      Para que los cambios se guarden en GitHub, la página necesita un token con permiso solo sobre este repo:
      1. GitHub → Settings → Developer settings → Fine-grained tokens → Generate new token.
      2. Repository access: Only select repositories → este repo.
      3. Permissions → Repository → Contents: Read and write.
      4. Pega el token aquí y elige la contraseña de edición.
      El token se guarda cifrado con la contraseña. Quien no la tenga solo puede ver.
